\doxysubsection{Detailed Description}
科学计算器核心类 

该类封装了表达式的语法分析、语法树构建和求值全过程。 使用递归下降解析器将输入的字符串表达式解析为抽象语法树（\+A\+S\+T）， 然后递归遍历 A\+ST 计算出最终结果。

\begin{DoxyNote}{Note}
所有异常通过 std\+::runtime\+\_\+error 抛出，调用者需捕获处理。 
\end{DoxyNote}
