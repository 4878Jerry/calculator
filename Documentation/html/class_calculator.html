Detailed Description

科学计算器核心类

该类封装了表达式的语法分析、语法树构建和求值全过程。 使用递归下降解析器将输入的字符串表达式解析为抽象语法树（AST）， 然后递归遍历 AST 计算出最终结果。

Note
所有异常通过 std::runtime_error 抛出，调用者需捕获处理。

double Calculator::evaluate ( const std::string &  expression)

计算表达式的值

Calculator::evaluate 的实现

Parameters
expression待求值的数学表达式，格式为字符串。 支持的语法规则：
  • 数字：整数或浮点数，如 123, 3.14
  • 四则运算：+ - * /，支持括号改变优先级
  • 幂运算：^，右结合，如 2^3^2 = 2^(3^2)
  • 一元正负号：+3, -5
  • 函数调用：函数名(参数)，如 sin(30)
  • 多参数函数：log(底数, 真数)
Returns
表达式的计算结果，类型为 double
Exceptions
std::runtime_error在以下情况会抛出异常：
  • 表达式语法错误（如括号不匹配、未知字符）
  • 除数为零
  • 函数定义域错误（如 ln(0)、sqrt(-1)）
  • 未知函数名
  • 负数底数进行非整数次幂运算
  • 对数底数 ≤ 0 或 = 1
Note
三角函数 sin/cos/tan 的参数采用角度制（度）， 如 sin(30) 返回 0.5
See also
https://en.wikipedia.org/wiki/Recursive_descent_parser

执行流程：

  1. 创建 Parser 实例解析表达式
  2. 得到抽象语法树（AST）的根结点
  3. 调用 eval 递归求值
  4. 释放 AST 内存
  5. 返回结果
