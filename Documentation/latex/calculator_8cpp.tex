本文件实现了表达式解析器（\+Parser）和求值器（eval）。 \begin{DoxyVerb}     ## 核心算法：递归下降解析 + 表达式二叉树

     文法定义（优先级从低到高）：

     expression = term { ('+'|'-') term }
     term       = factor { ('*'|'/') factor }
     factor     = unary
     unary      = '-' unary | '+' unary | power
     power      = primary [ '^' unary ]
     primary    = number | func '(' args ')' | '(' expression ')'
     args       = expression [ ',' expression ]

     ## 函数支持
     | 函数名 | 参数 | 说明 |
     |--------|------|------|
     | sin    | x    | 正弦（角度制）|
     | cos    | x    | 余弦（角度制）|
     | tan    | x    | 正切（角度制）|
     | ln     | x    | 自然对数，x > 0 |
     | log    | x 或 (底,真数) | 常用对数或任意底数对数 |
     | exp    | x    | e^x |
     | sqrt   | x    | 平方根，x ≥ 0 |
\end{DoxyVerb}
