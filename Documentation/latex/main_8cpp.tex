\doxysubsection{Detailed Description}
图形界面计算器 (Win32 G\+UI) 

\begin{DoxyAuthor}{Author}
裴振羽 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2026-\/08-\/27 
\end{DoxyDate}
\begin{DoxyVersion}{Version}

\end{DoxyVersion}
基于 Win32 A\+PI 的图形界面计算器。 核心计算复用 \mbox{\hyperlink{calculator_8h}{calculator.\+h}}/calculator.cpp 的表达式求值模块。

主要功能：
\begin{DoxyItemize}
\item 可视化按钮输入（数字、运算符、函数）
\item 实时显示表达式和计算结果
\item 历史记录管理（查看、搜索、删除、清空）
\item 菜单栏（历史管理、使用说明）
\end{DoxyItemize}

历史记录存储：history.\+txt（与表达式同一目录） 格式：每行为 \char`\"{}表达式 = 结果\char`\"{}

\begin{DoxyNote}{Note}
采用 Unicode (U\+T\+F-\/16) 作为窗口字符串编码， 内部核心使用 U\+T\+F-\/8/\+A\+S\+C\+I\+I，通过 utf8\+To\+Wide/wide\+To\+Utf8 转换。 
\end{DoxyNote}
